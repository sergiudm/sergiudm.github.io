03 / About

What I’m exploring

I’m interested in how execution traces can guide changes to an agent’s orchestration, including when it calls a tool, switches strategy, or stops. I build evaluation infrastructure so those decisions can be tested on real desktop tasks.

Before UCSC, I studied Automation at Southern University of Science and Technology and built decision-making and navigation software for the ARTINX RoboMaster team.
